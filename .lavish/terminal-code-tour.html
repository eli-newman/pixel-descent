1. Move into the project and list it

cd = change directory. ls = list. Folders show in blue.

zsh

4. Search all the code

rg (ripgrep, already installed) shows file:line: for every match.

zsh

5. Or just open it in an editor

zsh
$ cursor .
# opens Cursor with the file tree on the left and code on the right

The . means "this folder". Best for browsing a lot of files.
