# src

Source root. `main.ts` is the only entry (loaded by `index.html`), `style.css` styles the page around the two canvases (the slope and the HUD layer on top).

See the root `CLAUDE.md` for the layer diagram and dependency rules, and each subfolder's `CLAUDE.md` for its files.

| Path                                          | Job                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `main.ts`                                     | Builds `Store`, `Sfx`, `Input`, analytics, `Game`, `Framebuffer`, `SceneRenderer`, `Loop` once; wires resize, pause button, auto-pause, the share event; exposes `__game`, `__input`, `__store` in dev only. Analytics starts only when `__ANALYTICS__` (set in `vite.config.ts`) is not null, after the seed has left the address bar. Renders the slope (`SceneRenderer`, a `Framebuffer` sized by the layout: the frame plus `fitCanvas`'s `above` and `below` rows and one spare row, rebuilt when those change) into `#game`, placed so it reaches the screen's edges, and the HUD and menus (`renderUi`, a transparent `Framebuffer`) into `#ui`, sets the blend before each render and slides `#game` by `slideTransform`. Taps map through the `#stage` box (the frame). Sets `#stage`'s `data-phase`, `data-screen` and `data-color` for the CSS, and paints the page in the slope's snow colour wherever the slope does not reach. |
| `style.css`                                   | Page layout, pause button (yellow, or `--ink` in colour mode), safe-area probe, and `#wash`: the fade behind pause and game over (light) and the title's SCORES, GEAR and GOALS (almost all the way), in the slope's own tone.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `core/` `sim/` `state/` `platform/` `render/` | See their own `CLAUDE.md`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |

## Keeping docs in sync (mandatory)

When you change `main.ts` wiring or add a folder here, update this file and the root `CLAUDE.md` in the same change.
