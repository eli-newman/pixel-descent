# src

Source root. `main.ts` is the only entry (loaded by `index.html`), `style.css` styles the page around the two canvases (the slope and the HUD layer on top).

See the root `CLAUDE.md` for the layer diagram and dependency rules, and each subfolder's `CLAUDE.md` for its files.

| Path                                                    | Job                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `main.ts`                                               | Reads a dare link (`/c/<code>`, `core/dare.ts`) or an older `?seed=` link, clears it from the address bar before analytics starts, and builds the `Game` on that course with the dare. Builds `Store`, `Sfx`, `Input`, analytics, `Game`, `Framebuffer`, `SceneRenderer`, `Loop` once; wires resize, pause button, auto-pause, the share event; exposes `__game`, `__input`, `__store` in dev only. Analytics starts only when `__ANALYTICS__` (set in `vite.config.ts`) is not null, after the seed has left the address bar. Renders the slope (`SceneRenderer`, a `Framebuffer` sized by the layout: the frame plus `fitCanvas`'s `above` and `below` rows and one spare row, rebuilt when those change) into `#game` and the HUD and menus (`renderUi`, a transparent `Framebuffer`) into `#ui`, both through `SharpCanvas` (`platform/present.ts`) at the screen's own resolution: `#game` placed by `slopeBox` so it reaches the screen's edges and slid by `slideRows` inside its own pixels, `#ui` placed by `frameBox` on the frame. Sets the blend before each render. Taps map through the `#stage` box (the frame). Sets `#stage`'s `data-phase`, `data-screen` and `data-lesson` for the CSS, cuts a hole in `#wash` (`clip-path`) over the thing a tutorial lesson is about (`render/lesson.ts`). Dares are shared on the site the page is on (`new URL('.', location)`). |
| `style.css`                                             | Page layout, pause button (yellow), safe-area probe, and `#wash`: the fade behind pause, game over and a tutorial lesson (light), the title's SCORES, GEAR and GOALS (almost all the way) and the slope under the main title's menu (a gradient that leaves the mountains clear), in the slope's own black.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `core/` `sim/` `state/` `platform/` `render/` `server/` | See their own `CLAUDE.md`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |

When you change `main.ts` wiring or add a folder here, update this file and the root `CLAUDE.md` in the same change.
