# src/server

The Vercel functions: two behind dare links, and the analytics ingest route. `scripts/vercel-output.mjs` bundles each handler into one file of the deployment (see the root `CLAUDE.md`, Hosting and deploy). Nothing in the game imports this folder.

| File               | Job                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pageHandler.ts`   | `/c/<code>` (function `dare`): the game's page with the dare's link preview, or a redirect to `/` for a code that is not a dare. The built `index.html` is baked in at build time as `__INDEX_HTML__`. Cached by the CDN for 5 minutes only, since the page names this deployment's assets.                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `cardHandler.ts`   | `/c/<code>/card.png` (function `dare-card`): the dare card as a PNG, or 404. A code always draws the same card, so it is cached long (a new deployment starts a fresh CDN cache).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `page.ts`          | `darePage`: the built `index.html` with its own `og:` and `twitter:` tags swapped for the dare's (`dareTitle`: "Beat 1240 on Powline", `dareDescription`: the run in a sentence, the card as the image, absolute URLs on the request's origin) and a `<base href="/">`, so its relative asset paths still load from `/c/<code>`. Pure. Every value put in the page is HTML-escaped.                                                                                                                                                                                                                                                                                                                                                                |
| `card.ts`          | `cardPng`: `render/share.ts`'s `renderCard` at 200x105, every pixel blown up to a 6x6 square, as a 1200x630 PNG (about 8 KB).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `png.ts`           | `encodePng` (opaque 8-bit RGB, no filters, compressed with Node's zlib) and `crc32`. No dependencies.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `http.ts`          | `Req` and `Res`, the parts of Node's request and response the handlers use; `originOf` (the `https://host` Vercel forwards) and `queryParam` (the routes pass the code as `?code=`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `ingestHandler.ts` | `POST /flurry` (`INGEST_PATH`, function `ingest`): reads the body (at most `INGEST_MAX_BYTES`), rebuilds it with `cleanBatch` and posts it to PostHog's `/batch/` (`POSTHOG_UPSTREAM`, or the `POSTHOG_UPSTREAM` environment variable, which `scripts/serve-output.mjs` points at its stand-in) with only a `Content-Type` header, so PostHog never sees the player's IP or browser headers. The project key is baked in at build time as `__POSTHOG_KEY__` (from `VITE_POSTHOG_KEY`); without one every batch is dropped. Answers with a bare status (204, 400, 405, 413, 502), uncached. `ingest(req, res, deps)` takes the key, upstream and `fetch`, for tests. Built with `shouldAddHelpers: false`, so it reads Node's plain request stream. |
| `ingest.ts`        | `cleanBatch`: a batch for this project's key only, at most 50 events, each with a short `event` and `distinct_id`, an ISO `timestamp` and up to 20 flat snake_case properties (strings of at most 200 characters, numbers, booleans; nested values and every `$` property from the client dropped), then `country` from Vercel's `x-vercel-ip-country` (two letters), `$process_person_profile: false` and `$geoip_disable: true`. Pure.                                                                                                                                                                                                                                                                                                           |
| `node.d.ts`        | The project has no `@types/node`: the one Node API the server uses (`deflateSync`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |

## Rules

- Imports `../core` and `render/share` and `render/framebuffer` only (boundary lint). Of Node it uses only `node:zlib` (`node.d.ts`) and globals Node 22 shares with browsers (`fetch`, `TextEncoder`, `AbortSignal`); `process.env` is read through `globalThis`, since the project has no Node types. The card is the game's own drawing, so the preview and the image the share sheet sends are the same pixels.
- The handlers are plain Node `(req, res)` functions, so tests call them with fakes (`tests/server.test.ts`, the ingest one in `tests/analytics.test.ts`) and `scripts/serve-output.mjs` runs the bundled ones as they are.
- Never write a seed anywhere a player reads it: the card and preview show the score, metres, stars, tricks and how the run ended. The seed is only inside the code in the URL, as in every share link.

When you change anything in this folder (add, remove, rename a file, change an exported function, constant or rule), update this file in the same change, and the root `CLAUDE.md` if the routes or the build step change.
