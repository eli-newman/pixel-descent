# src/core

Foundation. Imports nothing from the rest of the game. Everything else may import from here.

| File         | Job                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `config.ts`  | Every tuning constant: canvas size (180x320), fixed step (1/120), speeds, jump spacing and mix (`FIRST_JUMP_Y`, `JUMP_GAP_MIN`/`MAX` measured from the end of the last landing zone, `JUMP_JITTER`, `CLIFF_CHANCE`, `KICKER_HALF`), jump lines (`LINE_START_M`, `LINE_CHANCE_START`/`END`/`M`, `LINE_THREE_CHANCE`, `LINE_RUNUP_MIN`/`MAX`, `LINE_MULTS`, `LINE_BONUS`), rider scale and board length (`RIDER_SCALE`, `BOARD_LEN`, shared by sim, state and render), storage keys (they keep the old `pixel-descent` name so saves survive the rename), the first-run tutorial (`TUTORIAL_RUNS`: runs that still get lessons; `LESSON_AHEAD_MIN`/`MAX`: how far ahead a thing stops the run; `LESSON_GUARD`: seconds before a tap goes on; `LESSON_FREE_RIDE`: px ridden before the first lesson about a thing), `ANALYTICS_MAX_PROPS` (properties per analytics event: 2 on Vercel Pro, 8 with Web Analytics Plus). |
| `rng.ts`     | Seeded PRNG, `normalizeSeed`, the daily seed (`dYYYYMMDD`). Same seed must always give the same course.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `detMath.ts` | `detExp`: `e^x` from `+ - * /` only, so it gives the same bits in every browser. Math.exp does not (V8 and JavaScriptCore differ).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `dare.ts`    | Dares: a finished run packed into a share link (`Dare`: course seed, score, metres, stars, tricks, how it ended as `DareEnd`, skis). `encodeDare` / `decodeDare` read and write the readable code (`k3m9qa-1240-312-4-3-t`, numbers clamped, anything else rejected), `darePath` is `/c/<code>`, `codeFromPath` finds the code in a path under any folder. Used by the game, the share card and the server, so all three agree.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

## Rules

- No DOM, no `window`, no imports from other `src/` folders.
- New tunable number: add it to `config.ts` with a doc comment.
- The dare code format is in links people have sent: change it only in a way `decodeDare` still reads the old codes.
- Changing `rng.ts` or `detMath.ts` output can change every course, which breaks shared seed links and per-seed boards. Do not do it casually.

## Keeping docs in sync (mandatory)

When you change anything in this folder (add, remove, rename a file, change an exported function, constant or rule), update this file in the same change. Update the root `CLAUDE.md` too if the layout or dependency rules move, and `README.md` if player-facing behavior or paths change.
